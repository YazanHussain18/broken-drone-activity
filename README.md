# Broken Drone 3D Challenge — GitHub Pages

موقع تفاعلي لنشاط **إصلاح الدرون** لبرنامج صيف طويق للدرونز.

## المميزات
- 9 مستويات.
- 3 مراحل صعوبة، وتزيد الصعوبة كل 3 مستويات.
- درون ثلاثي الأبعاد قابل للدوران.
- Drag & Drop: اسحب القطعة إلى مكانها على الدرون.
- دعم بديل للأجهزة اللمسية: اختر القطعة ثم اضغط مكانها على الدرون.
- تلميحات + زر فحص.
- نجوم لكل مستوى.
- انتقالات بين مراحل الصعوبة.
- واجهة عربية بسيطة تناسب الأطفال.
- Responsive للشاشة الكبيرة واللابتوب والتابلت.

## المستويات

### المرحلة 1 — مهندس مبتدئ
1. البطارية
2. المروحة
3. الكاميرا

المكان الصحيح يظهر بوضوح.

4. المحرك

خيارات أكثر، وآخر مستويين يحتاجان إصلاح قطعتين.

## تشغيله محلياً

لا تفتح `index.html` مباشرة إذا كان المتصفح يمنع تحميل بعض مكونات JavaScript.

من داخل المجلد شغّل:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## نشره على GitHub Pages

1. أنشئ Repository جديد في GitHub، مثلاً:
   `broken-drone-challenge`
2. ارفع **محتويات هذا المجلد** إلى جذر الـ repository:
   - `index.html`
   - `styles.css`
   - `game.js`
   - `assets/`
   - `.nojekyll`
3. افتح:
   **Settings → Pages**
4. اختر:
   **Deploy from a branch**
5. اختر:
   - Branch: `main`
   - Folder: `/root`
6. اضغط Save.

بعد النشر سيكون الرابط عادة:

```text
https://YOUR_USERNAME.github.io/broken-drone-challenge/
```
